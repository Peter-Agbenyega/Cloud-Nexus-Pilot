# AI Automation Agency

An agency-ready site for workflow design, AI operations, and business automation engagements across ops-heavy teams.

## Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- GitHub Actions placeholders for CI and deployment

## Getting Started

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env.local`
3. Start the dev server with `npm run dev`

## Included Pages




- Landing page
- Offers page
- Intake form page
- Case studies page
- Proposal request page
- Contact page
