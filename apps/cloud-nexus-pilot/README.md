# Cloud Nexus Pilot

A polished SaaS starter for interview prep, transcript uploads, prompt libraries, and AI-generated debriefs.

## Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- GitHub Actions placeholders for CI and deployment

## Getting Started

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env.local`
3. Start the dev server with `npm run dev`

## Included Pages

- Landing page
- Auth pages
- Dashboard shell
- Transcript upload page
- AI summary placeholder
- Prompt library page
- Pricing page
