# Cloud Security Digital Factory

A storefront-focused Next.js foundation for digital products like Terraform modules, security SOPs, and documentation kits.

## Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- GitHub Actions placeholders for CI and deployment

## Getting Started

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env.local`
3. Start the dev server with `npm run dev`

## Included Pages



- Landing page
- Catalog page
- Product detail page template
- Downloads placeholder
- Contact page
- Pricing and bundles page
