# DevOps Automation Agency

A modern agency site for pipeline acceleration, infrastructure modernization, cloud security hardening, and advisory engagements.

## Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- GitHub Actions placeholders for CI and deployment

## Getting Started

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env.local`
3. Start the dev server with `npm run dev`

## Included Pages


- Landing page
- Services page
- Case studies page
- Contact page
- Lead form page
- Booking placeholder
